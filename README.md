# 灵鸢实验室 · Lingyuan Lab

![灵鸢实验室标志](assets/logo/lingyuan-wordmark.svg)

**AI 时代工作与组织研究**  
*Researching Work and Organizations in the Age of AI*

> 看见工作如何改变，探索组织如何生长。

灵鸢实验室是一个公开、持续更新的研究项目。从组织发展（OD）的基本概念出发，结合真实工作场景与 AI 实践，探索 AI 如何改变任务、协作、决策、组织结构和人才系统。这里的“实验室”指开放的学习与探索方式；研究结论会标明证据、适用情境与尚未解决的问题。

## 核心问题

**当 AI 能参与知识工作，企业应该怎样重新设计工作与组织？**

我们沿着五条线索逐步研究：

1. **OD 基础**：组织是什么？OD 在改变什么？组织诊断与干预怎样发生？
2. **工作的构成**：任务、岗位、流程和价值如何区分？AI 改变了其中哪一层？
3. **人机共事**：人、AI 工具与 Agent 如何协作？判断、授权与责任怎样分配？
4. **组织设计**：团队边界、协调机制、决策权和管理方式如何演进？
5. **人才与 HR**：能力、培养、绩效、职业发展与员工体验需要怎样更新？

## 我们如何研究

每个主题从一个具体问题开始，依次整理经典理论、当代研究、真实案例与实践假设。文章会区分 **事实与研究证据 / 案例观察 / 个人推论 / 尚待验证的假设**。涉及企业实践时，先去除可识别信息和敏感数据。

主要成果是概念解释、阅读笔记、研究短文、案例拆解与可讨论的设计假设。项目先把问题研究清楚，再逐步形成方法。
