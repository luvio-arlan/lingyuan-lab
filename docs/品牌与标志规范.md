# 灵鸢实验室品牌与标志规范

版本：0.2 · 2026-09-28

## 名称与对外表达

| 用途 | 写法 |
| --- | --- |
| 中文主名 | 灵鸢实验室 |
| 英文主名 | Lingyuan Lab |
| 中文研究领域 | AI 时代工作与组织研究 |
| 英文研究领域 | AI-Native Organization Research |
| 中文一句话 | 看见工作如何改变，探索组织如何生长。 |
| 英文一句话 | Exploring how work changes and organizations evolve with AI. |

英文主名使用“Lingyuan”的拼音形式，保留中文名字的独特性；研究领域作为固定描述语，让第一次看到的人立即知道主题。对学术性或谨慎的场合，可用完整表达 *Researching Work and Organizations in the Age of AI*；“AI-native”用于研究领域和具体主题，不预设所有组织都已达到某种形态。

## 标志概念

图形只有一个单色轮廓：展开的双翼向中央收束，远看隐含字母 **Y**（Yuan）。它保留鸢的飞行感，也能在小尺寸下独立识别。中文字标以“灵鸢”为主体，“实验室”作轻量署名。**简约字标是默认标志**；在介绍项目的封面或独立图片中，另加 **AI-NATIVE ORGANIZATION RESEARCH** 描述研究领域。

标志的构成遵循单色、清晰轮廓与充分留白。图形无需逐项解释研究主题；名称和描述语共同完成识别。

## 颜色与字体

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 深墨 | `#17212D` | 标志与深色背景 |
| 暖白 | `#FBFAF7` | 浅色背景与反白标志 |
| 辅助灰 | `#55616C` | 正式署名中的描述语 |

中文字标使用宋体风格，英文使用 Avenir Next 或同类清晰无衬线字体。正文排版可继续使用系统黑体。SVG 中保留可编辑文字，跨设备展示时以导出的 PNG 为准。

## 文件

- `assets/logo/lingyuan-wordmark.svg`：简约字标，适合已有项目语境的页面。
- `assets/logo/lingyuan-lockup-light.svg`：带英文领域说明的浅色正式署名。
- `assets/logo/lingyuan-lockup-dark.svg`：带英文领域说明的深色正式署名。
- `assets/logo/lingyuan-mark.svg`：独立单色图形，用于头像与图标。
- `assets/logo/lingyuan-avatar.png`：暖白底头像，适合 GitHub 等圆形裁切场景。
- `assets/logo/lingyuan-social.svg`：社交封面与项目首页预览。
- 同名 `.png` 文件：便于在不支持 SVG 的场景中直接使用。

日常使用简约字标，并在相邻标题或简介中说明研究领域。单独传播的图片可使用正式横版，让“AI-NATIVE ORGANIZATION RESEARCH”可读。小头像仅使用独立图形。标志周围保留足够留白；不要拉伸、旋转、加装饰或添加底框。

目前标志使用可编辑系统字体；不同设备可能有细微字形差异。对外发布的固定画面使用已导出的 PNG。
