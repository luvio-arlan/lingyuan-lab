# 灵鸢实验室品牌与标志规范

版本：0.1 · 2026-09-28

## 名称与对外表达

| 用途 | 写法 |
| --- | --- |
| 中文主名 | 灵鸢实验室 |
| 英文主名 | Lingyuan Lab |
| 中文研究领域 | AI 时代工作与组织研究 |
| 英文研究领域 | AI-Native Organization Research |
| 中文一句话 | 看见工作如何改变，探索组织如何生长。 |
| 英文一句话 | Exploring how work changes and organizations evolve with AI. |

英文主名使用“Lingyuan”的拼音形式，保留中文名字的独特性；研究领域作为固定描述语，让第一次看到的人立即知道主题。对学术性或谨慎的场合，可用完整表达 *Researching Work and Organizations in the Age of AI*；“AI-native”用于研究领域和具体主题，不预设所有组织都已达到某种形态。

## 标志概念

图形由一笔向上的鸢翼、三枚连接点和一颗星组成。**鸢翼**对应观察与探索；**连接点**对应人、AI 与组织关系；**星**对应未知方向。图形本身承担识别，文字锁定研究主题。视觉上追求轻盈、清晰、审慎，避免将实验室误认作游戏或工具产品。

## 颜色与字体

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 深空蓝 | `#152137` | 主色、深色背景 |
| 晨光金 | `#D9AC73` | 星点与强调 |
| 雾蓝 | `#7CB6C8` | 连接与辅助线 |
| 云白 | `#F6F5F1` | 浅色背景 |
| 石墨 | `#1E2938` | 正文 |

中文建议使用系统黑体（苹方、思源黑体等），英文建议使用 Avenir Next 或同类清晰无衬线字体。SVG 中保留可编辑文字，跨设备展示时以导出的 PNG 为准。

## 文件

- `assets/logo/lingyuan-lockup-light.svg`：浅色背景横版主标志。
- `assets/logo/lingyuan-lockup-dark.svg`：深色背景横版标志。
- `assets/logo/lingyuan-mark.svg`：独立图形，用于头像与图标。
- `assets/logo/lingyuan-social.svg`：社交封面与项目首页预览。
- 同名 `.png` 文件：便于在不支持 SVG 的场景中直接使用。

使用时优先展示横版标志，让“AI-NATIVE ORGANIZATION RESEARCH”可读。小头像仅使用独立图形，在旁边的名称或简介中补足研究领域。保持标志周围至少一个星点直径的留白；不要拉伸、旋转或更换标志局部颜色。

目前标志使用可编辑系统字体；不同设备可能有细微字形差异。对外发布的固定画面使用已导出的 PNG。
